# 點個名

使用 HTML、CSS 與原生 JavaScript 製作的課堂隨機點名工具。所有程式都在 `index.html` 中，無須安裝套件或建置。

## 使用方式

1. 下載此儲存庫，以瀏覽器開啟 `index.html`。
2. 輸入姓名或座號，每行一位，也可用逗號分隔，再按「套用名單」。同名者請加上座號以區分。
3. 按「開始點名」隨機抽人；一輪結束後，按「新的一輪」重新開始。

也可以先按「試用範例」，載入虛構名單。

## 功能

- 每輪不重複抽選，顯示名單人數、尚未點到及已點人數。
- 可切換「已點紀錄」與「尚未點到」名單。
- 可在同一瀏覽器保存多個班級，每班各自有名單與本輪進度。
- 記錄本輪點名順序與時間。
- 支援空白鍵操作、手機版面與減少動態效果設定。
- 無外部資源依賴，可離線使用。

資料使用瀏覽器的 `localStorage` 儲存，不會上傳到伺服器。若瀏覽器限制儲存功能，頁面會提示；清除瀏覽器資料也會移除紀錄。

## 本機預覽

若已安裝 Python，可在專案資料夾執行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

接著開啟 <http://127.0.0.1:8765/>。停止預覽時，在終端機按 `Ctrl+C`。

直接開啟檔案與使用本機網址屬於不同儲存環境，兩者的名單不會自動共用。
